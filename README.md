# IFAO Mentorship 2025

Welcome to the IFAO Mentorship 2025 repository! This project is part of a mentorship program focusing on modern web development practices, accessibility, and CSS layout techniques.

## Project Overview

This repository contains practical exercises and demonstrations of frontend web development concepts, with a focus on:

- **CSS Grid and Flexbox layouts** 
- **Web accessibility standards**
- **Modern HTML5 semantic structure**
- **Responsive design principles**
- **SVG integration and icon systems**

## Current Demo: Travel Booking Interface

![Travel Booking Interface](https://github.com/user-attachments/assets/7d14be9a-f905-4c98-912e-45dd990788ed)

The main demonstration is a travel booking interface that showcases:

### Features Demonstrated
- **Grid Layout**: Uses CSS Grid for responsive button arrangement
- **Accessibility**: 
  - Skip links for keyboard navigation
  - Proper ARIA labels and roles
  - Focus management with visible focus indicators
  - Semantic HTML structure
- **Interactive Elements**: 
  - Primary and secondary button styles
  - Hover effects and transitions
  - SVG icon integration
- **Travel Services**: Interface for booking flights, trains, hotels, car transfers, and trip management

### Technologies Used
- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Grid layout, flexbox, custom properties, and modern styling
- **SVG**: Scalable vector icons for various travel services
- **Vanilla JavaScript**: (Ready for future enhancements)

## Getting Started

### Prerequisites
- A modern web browser
- A local web server (optional, for development)

### Running the Project

1. **Clone the repository**:
   ```bash
   git clone https://github.com/veselin-antonov/ifao-mentorship-2025.git
   cd ifao-mentorship-2025
   ```

2. **Serve the files** (choose one method):
   
   **Option A: Python (if you have Python installed)**
   ```bash
   python3 -m http.server 8000
   ```
   
   **Option B: Node.js (if you have Node.js installed)**
   ```bash
   npx serve .
   ```
   
   **Option C: PHP (if you have PHP installed)**
   ```bash
   php -S localhost:8000
   ```

3. **Open your browser** and navigate to `http://localhost:8000`

4. **Or simply open** `index.html` directly in your browser for basic viewing

## Learning Objectives

This project serves as a hands-on learning experience for:

1. **Modern CSS Layouts**: Understanding CSS Grid vs Flexbox and when to use each
2. **Web Accessibility**: Implementing WCAG guidelines and best practices
3. **Component Design**: Creating reusable, semantic UI components
4. **Performance**: Optimizing with SVG sprites and efficient CSS
5. **User Experience**: Focus management and intuitive interactions

## Accessibility Features

- **Skip Links**: Allow keyboard users to bypass navigation
- **ARIA Labels**: Provide context for screen readers
- **Focus Management**: Clear visual indicators for keyboard navigation
- **Semantic HTML**: Proper use of headings, buttons, and landmarks
- **Color Contrast**: Sufficient contrast ratios for readability
